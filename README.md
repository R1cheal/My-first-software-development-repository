# My-first-software-development-repository
This software repository contains my first software for the module Software Development. It stores all of the related files including a README file which contains information about the software I have written.

Software versioning refers to assigning different names to different versions or states of a software. A software is updated to patch up vulnerabilities in the sooftware, make it more efficient or incorporate user feedback. Versioning it i.e., naming software with different updates uniquely, helps in tracking the changes made across files and also keeping a backup in case something goes wrong and it needs to be traced back.
